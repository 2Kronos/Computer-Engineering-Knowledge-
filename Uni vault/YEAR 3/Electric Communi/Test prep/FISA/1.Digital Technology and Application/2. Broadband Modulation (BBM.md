**Broadband Modulation** is a transmission technique that **modulates a data signal onto a high-frequency carrier wave** to enable simultaneous transmission of multiple signals over a single communication channel.

**Definition:** Modulation technique that uses carrier waves to achieve high data rates over long distances.


**Purpose:**

- **Required to achieve broadband speeds** (hundreds of Mbps to Gbps)
- Enables long-distance, high-capacity communication


**Why Needed?**

- Baseband cannot achieve high data rates
- Need to transmit over long distances

### Phase Shift Keying (PSK) - Detailed Analysis

#### Understanding Constellation Diagrams

![[Pasted image 20251102063922.png]]

**What is a Constellation Diagram?**

- Graphical representation of modulation scheme
- X-axis: In-phase component (I)
- Y-axis: Quadrature component (Q)
- Each point represents a unique symbol (bit pattern)

**Key Concept:**

- Distance between points = Symbol spacing
- Closer points = More errors (ISI)
- More points = Higher data rate

---

#### 4-PSK (QPSK - Quadrature Phase Shift Keying)

![[Pasted image 20251102064038.png]]

**Configuration:**

- **4 phase states** (0°, 90°, 180°, 270°)
- Each symbol represents **2 bits**
- Symbol mapping: 00, 01, 10, 11

**Constellation:**

```
        Q
        |
   01   |   00
--------|--------  I
   11   |   10
        |
```

**Characteristics:**

- Moderate data rate
- Good symbol spacing
- **Lower ISI** - symbols well separated


**Data Rate Example:**

- Symbol rate = 1 Msymbols/sec
- Bits per symbol = 2
- Data rate = 2 Mbps

---

#### 8-PSK

**Configuration:**

- Each symbol represents **3 bits**


**Constellation:**

```
      Q
   010|011
 001  |  000
------|------  I
 100  |  111
   101|110
```

**Characteristics:**

- Higher data rate than 4-PSK (50% increase)
- **Reduced symbol spacing**
- **Higher ISI than 4-PSK**

**Comparison to 4-PSK:**


- Symbols closer together → More interference
- Phase detection more critical
- Increased error probability

---

#### 16-PSK - The Practical Limit

**Configuration:**

![[Pasted image 20251102093338.png]]

- **16 phase states** (22.5° apart)
- Each symbol represents **4 bits**
- 16 different symbols (0000 through 1111)

**Characteristics:**

- High data rate (4 bits per symbol)
- **VERY small symbol spacing**
- **Critical ISI problem**
- **Practical limit for PSK**

------

**Why Can't We Go Beyond 16-PSK?**

1. **Symbol Spacing Problem:**
    - Symbols too close together on circle
    

2. **Receiver Complexity:**
    - Must distinguish between very close phase values
    - Phase noise has greater impact


3. **Inter-Symbol Interference (ISI):**
    - Adjacent symbols interfere with each other
    - Timing errors cause overlap
    - Channel distortion makes detection unreliable

4. **Noise Sensitivity:**
    - Small phase errors cause wrong symbol detection
    - Requires very high SNR

### Quadrature Amplitude Modulation (QAM) - The Solution

#### Why QAM Was Designed

**Problem with High-Order PSK:**

- Symbols constrained to circle (constant amplitude)
- Only phase can vary
- Symbols get too close at high orders

**QAM Solution:**

- Varies **BOTH amplitude AND phase**
- Symbols distributed in 2D grid
- **Greater distance between symbols** than equivalent PSK



---

#### 4-QAM

**Configuration:**

- 4 symbols arranged in square grid
- Each symbol = 2 bits
- Two amplitude levels, two phase levels

**Constellation:**

![[Pasted image 20251102093056.png]]

**Equivalent to:** 4-PSK in performance **Use:** Foundation for understanding higher-order QAM

---

#### 16-QAM

**Configuration:**

- **16 symbols in 4×4 grid**
- Each symbol = **4 bits** (same as 16-PSK)
- Four amplitude levels, multiple phases

**Constellation:**
![[Pasted image 20251102093215.png]]

**Advantages over 16-PSK:**

- **Larger minimum distance between symbols**
- Better noise immunity
- Lower error rate for same SNR
- More practical implementation

**Symbol Spacing Comparison:**

- 16-PSK: Angular separation = 22.5° on circle
- 16-QAM: Grid separation = uniform in I-Q plane
- 16-QAM spacing ≈ 40% larger than 16-PSK

---

### 💡 Key Insights:

- **🎯 4-QAM = QPSK**: Same performance as 4-PSK
- **📈 Progressive Trade-off**: Higher QAM = More bits/symbol but needs better SNR
- **🛡️ Robustness Order**: 4-QAM → 8-QAM → 16-QAM → 32-QAM → 64-QAM (Decreasing)
- **🚀 Data Rate Order**: 4-QAM → 8-QAM → 16-QAM → 32-QAM → 64-QAM (Increasing)
- **🏆 Sweet Spot**: **16-QAM** offers the best balance for many practical applications

**🔍 Note**: 32-QAM uses a **cross-shaped constellation** (not a perfect square) to maintain better distance between symbols compared to a theoretical 6×6 grid.

### ISI (Inter-Symbol Interference) - Deep Dive

**Definition:** Distortion in signal where one symbol interferes with subsequent symbols.

**Causes:**

1. **Channel bandwidth limitation**
2. **Multipath propagation** (signals arrive at different times)
3. **Filtering effects** in transmitter/receiver
4. **Timing errors** in sampling

**Effect on Different Modulations:**

**PSK ISI Progression:**


**Why ISI Increases with PSK Order:**

- Symbols closer together
- Less tolerance for timing errors
- Channel distortion has greater impact
- Requires better equalization

**QAM Advantage:**

- Rectangular grid provides better separation
- ISI effects reduced compared to equivalent PSK
- Better performance with practical equalizers

### Constellation Diagrams - Drawing Requirements

#### Must Know How to Draw:

**4-PSK/QPSK:**
![[Pasted image 20251102100305.png]]

- 90° apart
- Label with bit patterns (00, 01, 10, 11)
- Show I and Q axes


**8-PSK:**

![[Pasted image 20251102100409.png]]

- 45° apart
- Label with 3-bit patterns
- Show I and Q axes

**16-PSK:**

- 16 points on circle
- 22.5° apart
- Can label subset of patterns
- Show I and Q axes
![[Pasted image 20251102100556.png]]

**4-QAM:**

- 2×2 grid (square)
- Four points at corners
- Label axes and bit patterns

![[Pasted image 20251102100721.png]]

**16-QAM:**

- 4×4 grid
- 16 points evenly spaced
- Show amplitude levels on both axes
- Label representative bit patterns

![[Pasted image 20251102100737.png]]



**Key Drawing Tips:**

- Always label I (In-phase) and Q (Quadrature) axes
- Show equal spacing in QAM grids
- Show circular arrangement for PSK
- Indicate relative amplitudes
- Mark at least some symbols with bit patterns
