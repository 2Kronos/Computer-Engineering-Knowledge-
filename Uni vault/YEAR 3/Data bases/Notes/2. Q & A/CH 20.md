
Here are straight-to-the-point answers to the review questions:

**20.1 Explain the purpose and scope of database security.**
- **Purpose:** Protect database against intentional/accidental threats
- **Scope:** Covers hardware, software, people, and data
- **Goals:** Prevent theft/fraud, maintain confidentiality, privacy, integrity, and availability

**20.2 The scope of database security extends beyond just DBMS controls. Discuss the role of the database administrator in database security and recovery.**
- Implements security and integrity constraints
- Performs regular backups
- Ensures recovery mechanisms are in place

**20.3 Explain the following in terms of providing security for a database:**
- **(a) authorization:** Granting rights/privileges to access system or objects
- **(b) authentication:** Verifying user identity (e.g., passwords, biometrics)
- **(c) access controls:** Mechanisms governing what users can do (DAC/MAC)
- **(d) views:** Virtual relations that hide sensitive data from unauthorized users
- **(e) backup and recovery:** Periodic copying of database and procedures to restore after failure
- **(f) integrity:** Constraints that prevent invalid data through rules and validation
- **(g) encryption:** Encoding data to make it unreadable without decryption key
- **(h) RAID technology:** Disk redundancy for fault tolerance and improved performance

**20.4 Distinguish between role and privilege in the context of object and systems privilege.**
- **Privilege:** Right to perform specific action (system privilege) or access specific object (object privilege)
- **Role:** Named group of privileges that can be granted to users
- **Key difference:** Privileges are individual rights; roles are collections of privileges for easier management

**20.5 Describe the security challenges associated with the use of DBMSs on the web.**
- Data travels "in the clear" over insecure protocols (TCP/IP, HTTP)
- Risk of eavesdropping and data interception
- Unauthorized access through web interfaces


**20.6 Describe the approaches for securing DBMSs on the Web.**
- Firewalls to filter network traffic
- SSL/TLS for encrypted communications
- Digital certificates for authentication

**20.7 Describe cloud computing services and the databases within their context.**
- Computing resources delivered over network, accessed via web browser/mobile app
- Provides scalable software/hardware resources remotely
- Lowers IT infrastructure costs and investment

**20.9 What tasks are associated with data administration?**

- Determining data requirements and setting standards
