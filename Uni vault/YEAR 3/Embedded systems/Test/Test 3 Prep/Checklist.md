# 1. Infrared Remote
- [x] Know how to decode IR commands (e.g., button presses from the virtual remote) using the IRremote.h library in Arduino code.  
- [x] Know how to map decoded IR values to specific actions (e.g., turning an LED on/off, changing a state).  
- [x] Know how to convert decoded IR values to ASCII characters and store/use them.  
- [ ] Know how to use the IR remote to control other components (e.g., send a number to a display, toggle a counter).  

# 2. 7-Segment LED Display
- [x] Know how to wire a single 7-segment display (Common Anode or Common Cathode) to an Arduino, including current-limiting resistors.  
- [x] Know how to write Arduino code to display specific digits (0-9) on a single 7-segment display using direct pin control.  
- [ ] Know how to multiplex multiple 7-segment displays to show multi-digit numbers (e.g., a 2-digit counter).  
- [x] Know how to display values received from an IR remote on a 7-segment display.  
- [ ] Know how to display the output of a binary counter on a 7-segment display (either directly or via a decoder).

- [x] Know how to send 4-bit BCD inputs from the Arduino to the decoder to display digits 0-9.
