**Distance Sensor and Calculator**

 Build the circuit as shown in the picture. The final result must show two LED’s lit up simultaneously. The one LED must show the distance detected in decimetres and the other one in the remaining centimetres. So the one LED shows the first “decimal” and the other one the second “decimal”. So each time after the one LED goes from the first to the last LED, the second LED should move up one position/LED. It is like the one LED is the long arm of a watch while the other LED is the short arm of the watch, but instead of telling time it is telling distance. Notice that you only have 8 LEDs. Thus you have shown the distance in such a way that it will show 8 * 8 = 64 different values instead of the known 10 * 10 = 100 different values. So, it should be counting in an octave way.

 While the sensing of the distance is happening, the user should be able to insert two values using the serial connection between the computer and the Arduino. These two values should be added and the result provided on the serial connection back to the computer. The distance sensing should not stop during this process. The user should not be prompted multiple times for a single input. The result must be shown on the computer’s serial monitor after two values are inserted. Thus, you can use two sequential entries to provide one result.
