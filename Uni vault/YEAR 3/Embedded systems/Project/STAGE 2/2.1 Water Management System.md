# Code 

```C++
const int VALVE_PIN = 8;         // Blue LED - Water Inlet Valve
const int PUMP_PIN = 9;          // DC Motor - Water Pump
const int WATER_SENSOR_PIN = A5; // Potentiometer - Water Level Sensor
const int START_BUTTON_PIN = 10; // Push Button - Start/Pause

int currentWaterLevel = 0;
bool startButtonPressed = false;

void setup() {
  initWaterSystem();
  Serial.begin(9600);
  Serial.println("Water Management System - Simulation 2 Step 1");
  Serial.println("---------------------------------------------");
}

void loop() {
  updateWaterLevel();      // Read water sensor
  controlValve();          // Manage water inlet valve
  controlPump();           // Manage drain pump
  checkStartButton();      // Check for user input
  
  displayWaterStatus();    // Show everything on Serial Monitor
  delay(1000);
}

// Initialize all water components
void initWaterSystem() {
  pinMode(VALVE_PIN, OUTPUT);
  pinMode(PUMP_PIN, OUTPUT);
  pinMode(WATER_SENSOR_PIN, INPUT);
  pinMode(START_BUTTON_PIN, INPUT_PULLUP);
}

// Read current water level
void updateWaterLevel() {
  int sensorValue = analogRead(WATER_SENSOR_PIN);
  currentWaterLevel = map(sensorValue, 0, 1023, 0, 100);
}

// Control water inlet valve
void controlValve() {
  if (currentWaterLevel < 80) {
    digitalWrite(VALVE_PIN, HIGH); // Valve OPEN - filling
  } else {
    digitalWrite(VALVE_PIN, LOW);  // Valve CLOSED - drum full
  }
}

// Control drain pump
void controlPump() {
  if (currentWaterLevel > 10) {
    digitalWrite(PUMP_PIN, HIGH); // Pump ON - draining
  } else {
    digitalWrite(PUMP_PIN, LOW);  // Pump OFF - drum empty
  }
}

// Check start button
void checkStartButton() {
  if (digitalRead(START_BUTTON_PIN) == LOW) {
    startButtonPressed = true;
    delay(300); // Simple debounce
  } else {
    startButtonPressed = false;
  }
}

// Display status on Serial Monitor
void displayWaterStatus() {
  Serial.print("Water Level: ");
  Serial.print(currentWaterLevel);
  Serial.println("%");
  
  Serial.print("Valve: ");
  Serial.println(digitalRead(VALVE_PIN) ? "OPEN - Filling" : "CLOSED - Full");
  
  Serial.print("Pump: ");
  Serial.println(digitalRead(PUMP_PIN) ? "ON - Draining" : "OFF - Empty");
  
  if (startButtonPressed) {
    Serial.println("START BUTTON PRESSED!");
  }
  
  Serial.println("---------------------------------------------");
}

// Read water level (public function for integration)
int readWaterLevel() {
  return currentWaterLevel;
}

// Check if drum is full (for future use)
bool isDrumFull() {
  return (currentWaterLevel >= 80);
}

// Check if drum is empty (for future use)
bool isDrumEmpty() {
  return (currentWaterLevel <= 10);
}
```

## **4. Component Initialization**
```cpp

  pinMode(VALVE_PIN, OUTPUT);     // Valve LED = output
  pinMode(PUMP_PIN, OUTPUT);      // Pump motor = output

```
- **Sets up** all pins correctly
- **INPUT_PULLUP** means button pressed = LOW, not pressed = HIGH

## **5. Water Level Reading**
```cpp
void updateWaterLevel() {
  int sensorValue = analogRead(WATER_SENSOR_PIN); // Read pot (0-1023)
  currentWaterLevel = map(sensorValue, 0, 1023, 0, 100); // Convert to %
}
```
- **Reads** potentiometer value
- **Converts** 0-1023 → 0-100% for easy understanding

## **6. Valve Control Logic**
```cpp
void controlValve() {
  if (currentWaterLevel < 80) {
    digitalWrite(VALVE_PIN, HIGH); // Valve OPEN - filling allowed
  } else {
    digitalWrite(VALVE_PIN, LOW);  // Valve CLOSED - drum full
  }
}
```
- **Opens valve** when water < 80% (need more water)
- **Closes valve** when water ≥ 80% (drum full - prevent overflow)

## **7. Pump Control Logic**
```cpp
void controlPump() {
  if (currentWaterLevel > 10) {
    digitalWrite(PUMP_PIN, HIGH); // Pump ON - draining allowed
  } else {
    digitalWrite(PUMP_PIN, LOW);  // Pump OFF - drum empty
  }
}
```
- **Turns pump on** when water > 10% (water to drain)
- **Turns pump off** when water ≤ 10% (drum empty - prevent dry running)

## **8. Start Button Check**
```cpp
void checkStartButton() {
  if (digitalRead(START_BUTTON_PIN) == LOW) {
    startButtonPressed = true;  // Button is pressed
    delay(300);                 // Debounce - ignore accidental presses
  } else {
    startButtonPressed = false; // Button not pressed
  }
}
```
- **Checks** button state
- **Simple debouncing** to avoid multiple detections

## **9. Display Function**
```cpp
void displayWaterStatus() {
  Serial.print("Water Level: "); Serial.print(currentWaterLevel); Serial.println("%");
  Serial.print("Valve: "); Serial.println(digitalRead(VALVE_PIN) ? "OPEN - Filling" : "CLOSED - Full");
  Serial.print("Pump: "); Serial.println(digitalRead(PUMP_PIN) ? "ON - Draining" : "OFF - Empty");
  if (startButtonPressed) { Serial.println("START BUTTON PRESSED!"); }
  Serial.println("---------------------------------------------");
}
```
- **Shows** all important information
- **Ternary operator** `? :` makes code compact
- **Clean formatting** with separators

## **How It Works Step-by-Step:**

1. **Reads the pin:** `digitalRead(VALVE_PIN)` returns either `HIGH` (1) or `LOW` (0)
    
2. **Checks the condition:**
    
    - If `digitalRead(VALVE_PIN)` returns `HIGH` (1) → **true**
        
    - If `digitalRead(VALVE_PIN)` returns `LOW` (0) → **false**
        
3. **Returns the appropriate value:**
    
    - **If true** → returns `"OPEN - Filling"`
        
    - **If false** → returns `"CLOSED - Full"`
